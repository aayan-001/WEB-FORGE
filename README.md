# Roshan Rozgar - AI Web Forge Hackathon

## About the Project
Roshan Rozgar is a hyper-local marketplace designed for trade workers, such as electricians and plumbers, in Pakistan. It addresses low-literacy accessibility challenges by incorporating voice-first onboarding and a streamlined local matching system.

## Project Structure
* roshan-rozgar-frontend: Mobile-first responsive web interface supporting both customer and worker views.
* roshan-rozgar-backend: Backend services running locally on port 3001.

## How to Run Locally

### 1. Run the Backend
1. Open the backend folder in your terminal.
2. Run your server command set "STATIC_DIR=C:\Users\Lenovo\Downloads\roshan-rozgar-frontend"
set PORT=3001
npm start.
3. The server will run on http://localhost:3001.

### 2. Run the Frontend
1. Open the frontend folder.
2. Access the interface through a local server in your browser.
